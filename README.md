AfricanThreads
==================

This is the repository for the [AfricanThreads]🚧.

**AfricanThreads** is an eCommerce platform dedicated to selling artisan products, enabling artisans to move their businesses online and expand their reach.

**Technologies Used:**
* PHP (server-side scripting)
* HTML, CSS, JavaScript (front-end) 
* Bootstrap (design and responsiveness) 
* MySQL (data management)
  
**Features:**
* Customers can browse products, add items to their cart, and create wish lists.
* Each product listing includes a description, features, and photos.

* Admin Interface: Manage products (add, update, remove), view and process customer orders, 
  update order status, and manage invoices.
